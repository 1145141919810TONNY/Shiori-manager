Shiori manager（管理器）与ShioriSigner（校验生成器）专用仓库

Shiori引擎本体：https://github.com/1145141919810TONNY/webgalgameengine

Shiori教学网页：https://1145141919810tonny.github.io/Shioriteaching/

Shiori Editor（可视化编辑器）链接：https://github.com/1145141919810TONNY/Shiori-editor

# 版本更新内容（2026/8/17）
## 管理器 V1.0.6 更新内容

### 新功能：月幕数据说明
- 底部「安装LEGUI」按钮组新增「月幕数据说明」按钮
- 月幕游戏数据来源为月幕 Galgame 在 GitHub 公开发布的归档导出（data-export）仓库：<https://github.com/ymgal/data-export/releases>，原始档案以 JSON Lines (.jsonl) 格式发布，共计 31546 条游戏记录
- 本程序运行时不访问月幕 API，所有数据均为编译期静态嵌入
- 弹窗顶部显示嵌入式数据的编译时间与收录游戏数（读取 `ymgal-games.json` 表头字段）
- 协议声明：遵循 data-export 仓库自身开源协议、不修改、不重新分发月幕原始数据

### 新功能：JSON 数据排序测试弹窗
- 底部「安装LEGUI」按钮组新增「JSON数据测试」按钮，位于「月幕数据说明」按钮的左侧
- 点击后弹出独立窗口，从嵌入式 `ymgal-games.json` 中随机抽取 10 条游戏记录
- 弹窗含两个表格：
  - **乱序表**（上表）：随机抽样顺序，点击「排序」按钮后走一遍 `HybridSortComparer` 排序逻辑
  - **参考表**（下表）：对同批数据用 `HybridSortComparer` 预排序，作为正确答案供对比
- 支持「排序」、「重新抽样」、「关闭」三个按钮，可反复验证排序与映射是否生效
- 列：序号 / 游戏名 / 假名读音 / 来源（日文原名 / 中文名→日文 / extensionName / 未命中回退）
- 底部状态栏显示命中/未命中数量统计

### 新功能：重命名弹窗下拉建议升级
- 输入框防抖查询现在聚合三个数据源：**专用读音词库**（147 条）+ **月幕日文原名**（约 3 万条）+ **月幕中文译名**（约 1.4 万条）
- 每条建议显示来源徽章区分：**专用**（人工词库命中）、**月幕**（月幕数据命中）、**Kawazu**（MeCab 转换）、**回退**（逐字 KanjiReadingData）
- 三库均未命中时，自动预览 Kawazu/逐字回退的降级转换结果，方便判断排序走向
- 输入框新增占位提示文字，空输入时显示「输入游戏名或假名读音（专用词库 + 月幕数据）」
- 无匹配时显示「无匹配建议，可继续手动输入」提示，而非直接关闭下拉
- 单字符输入时月幕扫描只取少量结果（3 条/源），多字符时正常取 8 条/源，兼顾响应速度与召回率

### 词典更新：GameReadingOverride V1.0.6 新增
- 专用读音词库新增 **33 条**词条，涵盖 Lass、Eroge Japan、Lose、NEKO WORKs、YUZUSOFT、あざらしそふと、Leaf、Key 等厂商作品
- 词库总条数由 114 条增至 147 条，详情请参考专用读音词库页面
- 现在词库的收录原则新增：收录一些首字为数字或拉丁字母的游戏名，但是前提是其本身是有明确的官方日语读音，比如：
  - `"11eyes 罪と罰と贖いの少女" = "いれぶんあいずつみとばつとあがないのしょうじょ"`

# 管理器 V1.0.5 更新内容（2026/8/13）
## 新功能：专用读音词库
- 新增`GameReadingOverride`专用词库，为日文游戏名提供精确的假名读音映射，优先级高于 Kawazu 形态素分析
- 词库命中时直接使用词库假名进行排序，无需经过 Kawazu 或回退词典，确保读音准确性
- 收录原则：仅收录首字符为 CJK 表意文字或假名的日文游戏名（含日厂中文译名），按厂商/系列分组维护
- 词条的内容会将符号等特殊字符忽略，仅保留游戏名的假名读音，以及会把片假名转换为平假名，还有把一些中文翻译转换为日语假名等，比如在词库中为：
  - "少女神域∽少女天獄" = "しょうじょしんいきしょうじょてんごく"
  - "夏空カナタ" = "なつぞらかなた"
  - "愛上火车" = "まいてつ"
- 词库的内容为手动维护，可能会存在错误或不完整游戏名的读音映射。目前仅收录了114条词条。词库内容可参考[此页面](https://1145141919810tonny.github.io/Shioriteaching/html/override-dictionary.html)

## 新功能：重命名与语言选择
- 重命名弹窗新增排序语言选择（中/日/英），必选项，默认为日语
- 重命名后语言自动锁定，主菜单的语言切换按钮将禁用并提示「请在重命名弹窗中修改」
- 重命名后游戏在列表中显示自定义名称，排序按所选语言走对应路径
- 输入名称时会自动匹配专用词库内容，从游戏名与假名读音两个维度进行包含匹配，最多返回 8 条候选建议，方便快速定位正确读音

## 新功能：文件格式检测工具
- 工具栏新增「文件格式检测」按钮（位于「打开校验器」之后），点击弹出独立检测窗口
- 通过分析二进制文件头（Magic Number）识别文件真实格式，支持压缩格式（ZIP/RAR/7Z/GZIP 等）、多媒体格式（PNG/JPEG/MP3/MP4 等）、文档格式（PDF/DOCX/XML 等）及游戏资源格式（XP3/Unity/KiriKiri 等）
- 仅读取文件头部 128 字节，不修改原始文件
- 对未知格式进行熵值分析，高熵文件提示可能为加密文件
  > 注意：检测结果仅供参考、仅能检测未加密文件、建议使用专用工具进一步分析

## 优化：五十音排序
- 优化假名排序逻辑，正确处理拗音（如きゃ/しゅ/ちょ等）与促音的组合假名排序
- 词库未命中时，日语侧统一走 Kawazu 整名转假名（含拗音/促音正确处理），仅在 Kawazu 初始化失败时回退到逐字符比较
- 新增`CompareKanaStrings`方法，按五十音顺序逐字符比较假名字符串，支持识别 2 字符拗音组合

# V1.0.2 更新内容（2026/6/26）

**新功能：游戏置顶 & 右键菜单**
- 右键游戏缩略图 → 弹出右键菜单，选择「置顶」可将游戏固定到列表最前面
- 再次右键 →「取消置顶」，游戏回到非置顶组最前
- 置顶不限数量，支持同时置顶多个游戏
- 置顶游戏右上角显示金色【置顶】标记
- 排序功能仅对非置顶游戏生效，置顶游戏始终保持原序并位于最前
- 拖拽排序时，置顶游戏只能与置顶游戏交换位置，非置顶游戏只能与非置顶交换
- 排序窗口同样支持右键菜单切换置顶/取消置顶，右侧同步显示【置顶】文字

**新功能：LEGUI / Locale Emulator 安装引导**
- 游戏详情栏新增「安装 Locale Emulator」引导按钮，当LE不可用时自动显示，一键跳转下载页面
- 底部状态栏新增「安装LEGUI」按钮，一键启动 LEInstaller.exe 安装器
- 启动安装器后自动弹出「LEGUI 安装提示」窗口（右侧定位，不遮挡安装界面），内置操作指引

**新功能：日语词典 & 排序方式**
- 接入 Kawazu（MeCab 形态素分析词典），日文游戏名称按五十音读音排序
- 内置 2500+ 常用汉字读音表（`KanjiReadingData`），词典外汉字自动回退
- 新增「按名称排序(A→Z)」按钮，混合语言智能排序（英文 → 假名 → CJK → 数字）
- 新增「排序规则说明」弹窗，详细解释分组优先级和排序策略

**视觉/体验优化**
- 排序窗口右键菜单整合（置顶 / 切换CJK语言），操作更直观
- 排序说明弹窗自动测量文本长度并适配窗口宽度
- 现在全盘扫描游戏时，新增二次确认弹窗与适当的提示词，以及新增动态扫描效果，可以准确知道当前管理器扫描到系统的哪一个文件

# V1.0.0 （2026/6/22） 发布

## 功能特性

### 游戏管理
- **全盘扫描** — 自动搜索系统中所有 Shiori 引擎游戏并添加到管理器
- **本地 Games 扫描** — 一键扫描管理器同目录下 `games/` 文件夹
- **手动添加** — 手动选择游戏根目录，自动识别 Shiori 引擎
- **拖拽排序** — 长按游戏缩略图拖动，自由调整排列顺序，自动持久化保存
- **移除游戏** — 从管理器列表中移除入口（不删除游戏文件）
- **一键清除** — 批量清空管理器中的所有游戏入口

### 游戏启动
- **正式版启动** — 识别 `Shiori.exe` 并一键启动
- **调试版启动** — 识别 `Shiori_debug.exe`，并一键启动调试版
- **双版本检测** — 同时存在两个版本时可分别启动
- **端口冲突处理** — 自动检测 8080 端口占用，提示并提供关闭占用进程选项

### 版本更新
- **自动检查更新** — 启动时静默检查，发现新版本时工具栏显示红点提示
- **手动检查更新** — 点击「检查更新」按钮，查看版本差异和更新日志
- **一键跳转下载** — 弹窗确认后自动在浏览器打开 GitHub Releases 页面
- **版本异常检测** — 本地版本不在官方版本列表中时发出安全警告

### 多语言支持
- **简体中文** — 默认语言
- **繁體中文** — 繁体中文
- **English** — 英文
- **日本語** — 日文

### 其他功能
- **游戏详情面板** — 展示游戏名称、版本、作者、制作组、类型、简介、版权等元信息
- **桌面快捷方式** — 一键在桌面创建管理器快捷方式
- **版权协议弹窗** — 内置版权协议查看（多语言），第三方开源许可协议完整展示
- **玩家指南** — 内置玩家使用帮助文档
- **开发者注意事项** — 内置开发者技术文档
